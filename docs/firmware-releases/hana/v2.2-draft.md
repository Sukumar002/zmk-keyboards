## Highlights

### Keymap and operating-system layout
- Unified `BASE` layer with macOS as the default and GUI/Alt layout shift for Windows.
- Retains `NUM`, `NAV`, `SET`, and `MOUSE` layers.
- Balanced mod-taps with a 200 ms tapping term and 175 ms quick-tap.
- Retains Bluetooth profile controls, USB/Bluetooth output toggle, mouse controls, combos, and ZMK Studio unlock control.

### ZMK Studio
- Reserves four runtime-addable layer slots so ZMK Studio can add/remove layers.
- Includes the reusable Studio runtime-layer helper and configuration for Studio RPC.
- Studio runtime-layer behavior is included in this build; individual editing workflows should be described as tested only to the extent verified on the user's device.

### OLED and dongle controls
- Adds a right-half key behavior to toggle the OLED.
- Adds a BASE display-view cycle behavior.
- Adds selectable display timeout options: 30 seconds, 60 seconds, 5 minutes, and never (default: 60 seconds).
- Adds selectable half-sleep timeout options: 5, 10, 15, and 30 minutes, and never (default: 15 minutes), with compatibility handling for older saved settings.
- Retains the existing Hana OLED layer/status UI and OS-aware modifier labels.

### Firmware included in build #109

The artifact contains eight UF2 images:
- Hana left-half BLE-central firmware with Studio support.
- Hana right-half BLE-peripheral firmware.
- Hana left-half BLE-peripheral firmware for dongle-central mode.
- Dongle-central firmware without display.
- Dongle-central firmware for 128×32 OLED.
- Dongle-central firmware for 128×64 OLED.
- Settings-reset image for XIAO nRF52840.
- Settings-reset image for nice!nano-compatible nRF52840.

## Compatibility and scope
- This is a Hana release only. It is not the universal-dongle implementation for sharing one dongle between Hana and Chocofi.
- Build #115 is deliberately excluded: it contains later shared-board/Studio adjustments and is not the known-good physical baseline selected for v2.2.
- Keep Hana v2.1 available as a rollback option.
