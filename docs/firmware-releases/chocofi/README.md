# Chocofi Firmware Releases

Chocofi firmware is tracked separately from Hana. **No stable Chocofi v1 release is published yet.** Feature parity and hardware validation are still in progress.

When ready, publish a board-specific release named **Chocofi Firmware v1.0** with a tag such as `Chocofi_v1.0`. Include the tested build artifact, source commit, firmware variants, keymap/combo behavior, and hardware validation notes.

Do not treat intermediate successful Actions builds as stable releases.
